# Convex backend

`convex/_generated/` is committed so `npm run typecheck` works without a
running deployment, but it is regenerated whenever you run Convex locally —
don't hand-edit it.

## Local development

```bash
npx convex dev
```

This configures (or reuses) a Convex deployment, writes `.env.local` with
`CONVEX_DEPLOYMENT` / `NEXT_PUBLIC_CONVEX_URL`, and regenerates
`convex/_generated/` on every schema or function change.

## Non-interactive / agent environments

`npx convex dev` prompts for a team/project on first run. For CI or agent
sessions with no TTY, use anonymous mode to get a local-only deployment
without any Convex account:

```bash
export CONVEX_AGENT_MODE=anonymous
npx convex init      # configures a local deployment, writes .env.local
npx convex codegen --typecheck disable   # regenerates convex/_generated/
```

`convex/tsconfig.json` is generated by Convex and describes the isolated
environment Convex functions run in (no DOM APIs beyond what's declared,
`isolatedModules`, etc.) — it typechecks independently of the root
`tsconfig.json`, which also includes `convex/**/*.ts` for editor/CI
convenience.
